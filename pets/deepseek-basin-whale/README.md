# 吃白饭的大肥鱼——哦鲸鲸的codex桌宠

顶盆大肥鱼原生v2动画资源包。

## Windows安装

将整个 deepseek-basin-whale 文件夹复制到 %USERPROFILE%\.codex\pets\。
若设置了CODEX_HOME，则放到该目录下的pets文件夹。
确认 deepseek-basin-whale/pet.json 与 spritesheet.webp 在同一层。
刷新客户端Pets列表并选择“顶盆大肥鱼”；没有出现时完全退出后重新打开客户端。
已有同名版本时请先备份旧文件夹，其他宠物可保留。

需要客户端支持自定义v2 Pets。这个包包含9组动作、16个注视方向；不包含DSH插件的点击喂饭、摸头或换装菜单。
